# Microsoft-Homepage-Clone
Microsoft homepage clone built using HTML and CSS with Flexbox and Grid layout. Includes responsive navbar, hero section, product grid, business section, and multi-column footer. Structured using modular CSS files for maintainability.


This is a frontend clone project built for learning purposes.
The website is recreated using HTML, CSS/TailwindCSS.

It is only for educational and portfolio purposes.
